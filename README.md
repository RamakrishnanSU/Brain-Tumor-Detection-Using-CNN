# Brain Tumor Detection Using CNN

This project uses Convolutional Neural Networks (CNN) to detect brain tumors from MRI scan images.

## Features

- MRI image preprocessing
- Brain contour extraction
- Data augmentation
- CNN-based binary classification
- Accuracy and loss visualization

## Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
